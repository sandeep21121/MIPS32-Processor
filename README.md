# MIPS32-Processor
This project simulates a 5-stage pipelined MSP32 processor using Verilog HDL.  Features 5-stage pipeline: IF → ID → EX → MEM → WB Supports instructions: ADD, SUB, AND, OR, MUL, SLT, ADDI, SUBI, LW, SW, BEQZ, BNEQZ, HLT Basic branching and memory operations Two-phase clocking (clk1, clk2) Instruction memory and register file simulation
